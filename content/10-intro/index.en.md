## Overview

This workshop assumes that you have a good understanding of the generative AI space and are familiar with services like Amazon Bedrock and AWS Lambda. Hands-on experience with Python is recommended.

Familiarity with basic financial markets concepts (stocks, portfolios, trading) is helpful but not required — all financial data in this workshop is simulated.

You have two options to run this workshop:

- [At an AWS event](./11-at-aws/)
- [Self-paced in your own AWS environment](./12-self-paced)

The workshop contains a number of examples of how to work with AgentCore CLI.

This workshop is focused on the command-line experience offered by AgentCore CLI, so it is recommended to set up a proper Python environment as shown in the next steps and work with your preferred developer IDE. We suggest working with [Kiro](https://kiro.dev/).

The prerequisites CloudFormation stack provisions the necessary IAM roles, VPC resources (subnets, security groups, and VPC endpoints), and supporting infrastructure required to run the workshop examples.

Now, click on one of the options above and let's get started!
