## Overview

This workshop assumes that you have a good understanding of generative AI area and are familiar with solutions like Amazon Bedrock, AWS Lambda, and hands on experience with Python is recommended.

You have two options to run this workshop:

- [At an AWS event](./11-at-aws/)
- [Self-paced in your own AWS environment](./12-self-paced)

The workshop contains a number of examples of how to work with AgentCore CLI.

This workshop is focused in command-line experience that is offered by AgentCore CLI, so it's recommended to make proper Python setup as shown in next steps and work with your prefered developer IDE, we will suggest to work with [Kiro](https://kiro.dev/).

Now, click on one of the options above and let's get started!
